Relative pricing, not a forecast

The power-law model does not claim to know the future distribution of returns. It takes one observed out-of-the-money option price as an anchor and asks what a further strike should cost if the tail decays like a Pareto law with index α > 1. The BSM tab is a conventional benchmark.

Power-law tail formula

C(K2) = C(K1) × [(K2 − S0) / (K1 − S0)](1−α)

Where K1, K2 > S0 (out-of-the-money calls) and α > 1.

P(K2) = P(K1) × [α − r2(1−α) − (α−1)r2] / [α − r1(1−α) − (α−1)r1]

Where r = (S0 − K) / S0 is positive for out-of-the-money puts, and α > 1.

Black-Scholes-Merton formula

C = S × N(d1) − K × e−rT × N(d2)

P = K × e−rT × N(−d2) − S × N(−d1)

d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T), d2 = d1 − σ√T. No dividends; European exercise.

How this is built

The pricing formulas, validation and orchestration are one pure Python model. The CLI calls it directly; this page calls the same model through a thin JavaScript gateway and a CPython runtime compiled to WebAssembly (Pyodide). There is no Python server and no second implementation of the math.

Educational project. Not investment advice. The power-law model is a relative tail-pricing heuristic, not a no-arbitrage model.
